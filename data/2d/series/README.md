# 2D series (temperature / field dependent)

Stacks of 2D slices against a control parameter — e.g. the same reciprocal-
space plane measured at several temperatures, tracking diffuse features or
superlattice peaks through a transition.

One file per parameter value (parameter in the filename) or a single stacked
HDF5 file — either works. In `INVENTORY.md`, note the parameter values and
what changes across the series that the tools should be able to detect.
