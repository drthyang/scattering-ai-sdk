# 1D curves

Single 1D patterns: powder diffraction, total scattering S(Q)/F(Q), PDF
G(r)/D(r), inelastic cuts, or line cuts extracted from 2D data.

Ideal starter set:

- one **clean** curve with well-separated peaks (easy fitting baseline)
- one **ugly** curve: weak/overlapping peaks, sloping or curved background,
  realistic noise (this is what the robust fitter must survive)
- one curve where **rebinning or FFT** is part of the workflow you actually do

Any column format is fine — note the column meanings in `INVENTORY.md`.
